## Which platform and hosted models fit modulo?

### Takeaway

Use Token Factory serverless for the small text-to-preset call. Evaluate a separate GPU environment for actual audio separation. Self-hosting an LLM adds infrastructure work before there is evidence it helps this six-control task. This recommendation is an engineering inference, not a benchmark result.

### Cited Findings

- Token Factory exposes an OpenAI-compatible inference API; AI Cloud offers GPU VMs for custom stacks; Serverless AI runs containers as jobs and endpoints. These are different deployment products, not interchangeable names for an audio model. [Nebius developer overview](https://dev.nebius.com/)
- The live public catalog returned these exact model IDs and prices. Prices are USD per million tokens; a dash means no cached rate was supplied, not a free cache. All rows are public candidates, not verified availability for Isyraf's eventual account. [Public catalog JSON](https://tokenfactory.nebius.com/api/public/models_info)

Therefore neither cookbook membership nor a NVIDIA audio-capable model card establishes an available Token Factory audio endpoint. The visible chat API reference has no audio-specific field documented in its rendered text. [Cookbook Nemotron index](https://github.com/nebius/token-factory-cookbook/blob/main/models/nemotron/README.md), [chat API reference](https://docs.tokenfactory.nebius.com/api-reference/inference/create-chat-completion)
- Authenticated `GET https://api.tokenfactory.nebius.com/v1/models` lists models for the credential/project; optional `ai_project_id` and `verbose` are documented. A successful model list proves discovery/authentication, not successful inference. [List models](https://docs.tokenfactory.nebius.com/api-reference/models/list-models)
- JSON output supports `response_format` types `json_schema` and `json_object`, but Nebius says support varies by model and to look for the model's JSON-mode tag. The current Nemotron catalog rows do not carry that tag. Strict schema support for the shortlisted IDs is therefore an explicit smoke-test gate. Some documentation examples contain syntax mistakes; do not copy them verbatim. [Structured outputs](https://docs.tokenfactory.nebius.com/ai-models-inference/json), [public catalog](https://tokenfactory.nebius.com/api/public/models_info)
- `max_completion_tokens` is documented to include visible output and reasoning tokens. `max_tokens` has an 8192 default if omitted. Use an explicit completion bound; do not send both caps just because the autogenerated example does. A complete response can still be empty or truncated if reasoning consumes the allowance. [Chat API](https://docs.tokenfactory.nebius.com/api-reference/inference/create-chat-completion)
- Current rate limits are account-specific and dynamic; use dashboard/response headers and handle HTTP 429. The example 60 RPM/400,000 TPM is illustrative, not this team's allocation. [Rate limits](https://docs.tokenfactory.nebius.com/ai-models-inference/rate-limits)

### Inferences

- First compare Nano and Super on identical measured features, exact existing schema, token limit, and dry-guitar listening cases. Bigger context and generic reasoning benchmarks do not demonstrate better tone approximation.
- Keep audio separation outside Token Factory text calls. Do not send WAV bytes to a text-only model or infer that vision means music understanding.
- An NVIDIA-hosted API is useful as an independent capability experiment; it does not by itself meet the Nebius runtime requirement. Self-hosted NIM on Nebius could meet deployment requirements but would require compatible hardware, container/profile setup and maintained endpoints. NIM availability/licensing differs by offering. [NIM offerings](https://docs.nvidia.com/nim/large-language-models/latest/about-nim-llm/nim-offerings.html)

### Gaps

- No authenticated model list, regional routing test, inference result, JSON-schema compatibility, model-specific reasoning toggle or measured latency was obtained. `enable_thinking`, `thinking` and `reasoning_effort` are not interchangeable; no universal Nano/Super toggle was verified in Nebius's API docs.
- The catalog is a live current listing, not an archived dated availability guarantee. Its `created_at` values are not reliable evidence of model release dates. Exact release-history verification belongs to NVIDIA model cards. Do not treat newer-looking names as previously available just because a cookbook mentions them.
- Nemo/Omni custom deployment, NVIDIA-hosted audio input formats and music competence need their own real input test.

## What access, credits and running costs should Isyraf expect?

### Takeaway

Start with account/offer verification, not a GPU. A documented credit offer is not money already in this user's account, and a credit balance is not a guaranteed hard spending cap.

### Cited Findings

- The current free Builder Program advertises **$25 Token Factory credit**. Its documented path is join, verify email, and claim credits. Partner offers are subject to eligibility, availability and individual terms. It does not promise this Malaysian user's acceptance, a redemption deadline, credit expiry or AI Cloud GPU funds. [Builder Program](https://dev.nebius.com/builders)
- Token Factory onboarding currently requires a billing account and bank card. It separately documents a **$1 trial valid for 30 days**. Card balances are debited in real time and can become negative, followed by automatic card charging at month start or a configured threshold. Do not assume trial/Builder offers stack. [Billing](https://docs.tokenfactory.nebius.com/other-capabilities/billing-new)
- Promo redemption: click balance → Top up → With promo code → enter code → Top up; verify the Transactions entry. Promo codes commonly expire and cannot settle outstanding invoices. Record the actual amount, service scope and expiry from the resulting dashboard, rather than assuming all credits can pay GPU costs. [Billing](https://docs.tokenfactory.nebius.com/other-capabilities/billing-new)
- GPU VMs bill running GPU/CPU/RAM by the second; stopped compute is not charged, but disks/shared filesystems remain billable. H100 is **$4.50/GPU-hour after October 1**. L40S GPU alone is $1.35/hour **plus CPU/RAM**; the public prices page advertises complete presets from $1.55/hour. RTX PRO 6000 is $1.80/GPU-hour. Confirm the full chosen preset/storage/tax quote in the console. [Detailed compute pricing](https://docs.nebius.com/compute/resources/pricing), [pricing summary](https://nebius.com/prices)
- AI Cloud's pricing summary states a $25 minimum first payment. It is a cloud payment condition, not an inference-test cost or a guaranteed promotional grant. Spot prices can change during use; preemptible jobs may lose capacity. [Pricing summary](https://nebius.com/prices)
- AI Cloud Serverless jobs/endpoints/devlabs use Compute VM/disk pricing while running; a stopped endpoint has no compute/storage charge, a stopped devlab retains disk charges, and jobs cannot be stopped. Mounted buckets/filesystems have separate charges. [Serverless pricing](https://docs.nebius.com/serverless/pricing-quotas)
- Token Factory dedicated endpoints are billable while at least one replica runs; zero replicas means unavailable and no endpoint charge. Serverless per-token inference is the simpler initial choice for low request volume. [Dedicated endpoint billing](https://docs.tokenfactory.nebius.com/ai-models-inference/dedicated-endpoints/billing-policy)
- Official hackathon rules require a working application using at least one NVIDIA open-source model and a runtime Token Factory call or qualifying AI Cloud compute. Best Apps and Agents specifically describes Nemotron on Token Factory. Deadline: October 30, 2026, 10:00 PDT = October 31, 01:00 MYT. Judging access must remain until December 15, 2026, noon Pacific. [Official rules](https://nebiusglobalaihackathon.devpost.com/rules)

## How can the team set up and test safely?

### Takeaway

Complete the no-spend preparation now. Run authenticated discovery after Isyraf creates the account, and make one bounded inference only after the actual credits and a spending cap are recorded.

### Cited Findings

1. Join the [hackathon](https://nebiusglobalaihackathon.devpost.com/rules) and [Builder Program](https://dev.nebius.com/builders); verify email and inspect the actual credit claim terms.
2. Create/sign in to [Token Factory](https://tokenfactory.nebius.com/) with Google/GitHub. Review card/onboarding terms personally, create a project/API key, redeem any actual offer and verify amount/expiry. Use a server-side key, never a `VITE_` variable or issue comment. [Quickstart](https://docs.tokenfactory.nebius.com/quickstart), [billing](https://docs.tokenfactory.nebius.com/other-capabilities/billing-new)
3. Inspect the [public catalog](https://tokenfactory.nebius.com/api/public/models_info) without credentials. Then run authenticated GET `/v1/models`; choose the exact returned NVIDIA ID, preserving case. [Models API](https://docs.tokenfactory.nebius.com/api-reference/models/list-models)
4. Reuse the existing API Python 3.12 virtual environment. The following **unexecuted example** uses only Python's standard library. Run as a temporary local file outside Git using `services/api/.venv/Scripts/python.exe`; enter the key at the hidden prompt. It performs discovery only unless deliberately changed. Endpoint, Bearer authentication and cap names follow [Nebius models](https://docs.tokenfactory.nebius.com/api-reference/models/list-models) and [chat reference](https://docs.tokenfactory.nebius.com/api-reference/inference/create-chat-completion).

```python
import getpass
import json
import urllib.error
import urllib.request

base = "https://api.tokenfactory.nebius.com/v1/"
key = getpass.getpass("Token Factory API key: ")
headers = {"Authorization": f"Bearer {key}", "Content-Type": "application/json"}
request = urllib.request.Request(base + "models", headers=headers)
try:
    with urllib.request.urlopen(request, timeout=30) as response:
        ids = {item["id"] for item in json.load(response)["data"]}
    print("NVIDIA IDs:", sorted(x for x in ids if x.startswith("nvidia/")))
    run_one_paid_call = False  # Change only after credit/cap verification.
    if run_one_paid_call:
        model = "nvidia/NVIDIA-Nemotron-3-Nano-30B-A3B"
        if model not in ids:
            raise SystemExit("Selected model is unavailable; choose from discovery.")
        payload = {"model": model, "messages": [{"role": "user",
                   "content": "Reply with one short sentence confirming receipt."}],
                   "max_completion_tokens": 1024, "store": False}
        request = urllib.request.Request(base + "chat/completions",
            data=json.dumps(payload).encode(), headers=headers, method="POST")
        with urllib.request.urlopen(request, timeout=30) as response:
            result = json.load(response)
        choice = result["choices"][0]
        if choice.get("finish_reason") != "stop" or not choice["message"].get("content"):
            raise SystemExit("Incomplete/empty response; inspect usage before retrying.")
        print({"id": result.get("id"), "model": result.get("model"),
               "usage": result.get("usage"), "content": choice["message"]["content"]})
except urllib.error.HTTPError as error:
    raise SystemExit(f"Provider HTTP {error.code}; no automatic retry.")
except (urllib.error.URLError, TimeoutError):
    raise SystemExit("Network/timeout; billing outcome unknown; check usage before retry.")
```

### Inferences

- After the first response, test `json_schema` compatibility with the existing `contracts/preset.schema.json`; compare plain JSON prompting if schema mode is rejected. Do not silently switch model/provider or count a fixture as generated output. Reuse the existing `validate_preset` in `services/api/app/contracts.py`, including finite-number checks.
- Test measured-feature cases with only input gain, drive, bass/mid/treble and master gain. Never ask for cabinet/delay/reverb until those controls exist in the runtime schema and engine. Keep server-owned provenance outside model authority.
- For the separator, after a separate compute cap is agreed: create a single-GPU VM, compatible Ubuntu driver image and SSH access; record the full quoted resources, run `nvidia-smi`, test one tiny rights-cleared clip, pin the successful environment, then run three representative clips. Download results before cleanup. Stop the VM and explicitly inspect retained disk charges. The official quickstart includes an eight-GPU training tutorial; modulo does not need to follow that part. [Compute quickstart](https://docs.nebius.com/compute/quickstart)
- A containerized Serverless job becomes useful after the separator environment works; an endpoint is useful for ongoing asynchronous requests. Neither cloud path belongs in live guitar playback.

### Gaps

- Example is documentation, not a production provider implementation. No authenticated execution, JSON schema call, listening test or cost measurement happened. Connection timeout does not guarantee provider cancellation; inspect usage before retrying.
- No paid infrastructure, extra dependency, prompt tuning or app source change was performed. Current risks are account/credit activation and obtaining honest real-audio/model evidence before the deadline.
